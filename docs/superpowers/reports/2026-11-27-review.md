PR #335: **approve** — No sensitive-path hold applies. The PR touches only frontend/src/ask/AnswerPage.jsx and AnswerPage.test.jsx, none of them on the denylist (backend/auth/, backend/config_store.py, .github/workflows/*, migrations, backend/retrieval/search.py).

The change matches issue #317 and stays within its scope and file list. The diff is about 93 lines, under the 150-line target.
- The "Copy as Markdown" button calls navigator.clipboard.writeText with the answer text.
- Each citation marker becomes a markdown link to that citation's real commit/PR URL. This preserves the citation traceability CLAUDE.md requires. parseAnswer only emits markers for known citation IDs, so the citationsById lookup can't return undefined.
- "Copied" shows in a role="status" span.
- A missing clipboard or a rejected writeText is caught, so nothing throws and "Copied" is not shown.
- The button sits inside the existing print:hidden container, so it is hidden in print.
- The three new tests cover the issue's acceptance criteria. They check the written markdown with URLs, the missing-clipboard case, and the rejected-write case.

A nit that doesn't block merging: the "Copied" state is never reset, so it stays visible until the page re-renders.
